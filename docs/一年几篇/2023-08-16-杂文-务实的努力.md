# 杂文-务实的努力，草稿
1、有用无用的谬论

我的一个朋友跟我说了几次同一个问题：“我到底有没有必要学日语等等事情呢，可是我科研用不上啊”

这不禁让我想起我自己十七岁上大学前受的家庭学校教育观念——啥都不准做，要学习考好大学。然而我最终也并不能考得有多好，当初大一军训时想退学复读，打电话和马健斌聊这个问题，他认为复读一年并不会有什么提升。我有点绝望地发现在之前的学习方式下确实不大可能再考得更好了，遂放弃了。

我记得上高中以后才开始用辅导资料，才发现生物的课外资料原来早就总结好了知识点，直接拿来背效率可以提升很多、我记得上高中才知道可以用多种颜色的笔做笔记、上高中才渐渐搞懂了练字怎么才能好看，你要说这些东西有什么大用处么，倒也不见得，毕竟我上高中前这些都不会，成绩排名反而更高——尽管我非常明确，如果我没学这些，高中的成绩一定是更差的。

我的一个高中同学，上课时他很多地方都能附和老师几句，我好奇，于是问他从哪里知道这些杂七杂八的冷门知识的，他说的都是我不晓得的来源，后来才注意到他一周起码得读完两本书，各种科普书乃至能充当大学教材（毕竟国内大学教材也就那样）的兴许也是有一些的，或许是走马观花不求甚解地看看，但是他会想“在读这些书之前考虑一下之后用不用得上“么

其实恰恰，老师认为我们可能用得上的拉格朗日中值定理，当时一听说这是大学才学的东西，学起来可紧张了，高考照样也没用上，甚至上大学了再学时我还是不懂也不会用，但是就是因为好奇而去看的相对论公式，我到现在还记得有个根号，里面有个速度和光速的比值这么个大致框架。

我一个大学同学，他高中学化学竞赛，而我高中时学校禁止学习竞赛，理由是影响高考，的确，他学的化学竞赛并没有帮到高考，他还是和我一样来了浙大，甚至他高考分数大概是比我低好些的。但是到大学后他不用学习什么普通化学跟有机化学了，因为这些都比高中化学竞赛难度小不少，于是他不到大三就开始了实验室生涯，现在在同一个实验室经历有两年多了，我却还没有找到一个适合自己的实验室。

2、功利而务实的努力

讲了这么多例子，其实只是想说——大多数人理解的“有用的努力”和“无用的努力”其实还是蛮短浅和蛮可笑的。

因为这种有用和无用，其实就是要学习成绩高、名牌大学毕业、高薪资好待遇的工作——所谓的科研现在也是当一门体面又赚钱工作在做嘛。所以说白了，普世价值是什么？钱、权、社会低位。我们称某某艺人最多就是“大师”，但是怎么表现他很厉害？他曾经给某某领导表演过，怪不得我们打心眼里瞧不起他们，“戏子而已”，“学习成绩不好的才去学艺术”。

如果是这样的话，我其实建议有用的努力是重启人生，如果投胎不好就接着重启，直到投到富而贵的人家，然后什么叫有用的努力呢？问爸妈，爸妈自身不会也会告诉你去问哪个叔叔阿姨或者哪个教授，你多听听建议，然后看看谁给你钱谁给你毕业给你工作，就听谁的，准没错。这样既不费力又保险。

如果不想重启人生，那也是一样的，最简单的努力就是傍上一个已经成功已经“有用”的人物，陪他/她睡觉也好、塞钱也好、磕头也好、帮他天天打扫办公室也好，都ok的，只有道德之高低、处理是否得体、没有行为性质上的区别，然后重复上面的——谁决定你的好处就听谁的。

其实现实生活中，大多数成功的人就是这样努力的——如果你看看“不羡鸳鸯不羡仙 只羡侯总每一天”的侯天来出演的作品，里面的人大多都是这样的，实际生活中我们最推崇的也是这样的努力，尽管里面可能被分别划到“智慧”“情商”“下贱”中去。这种方式的原理在于，越是利益共同体越竭诚为你做最理性的判断，所以记得傍上他们时候要多掌握他们的把柄以及多捆绑一些利益，所以陪睡觉比打扫办公室保险性更高。君子性非异也，善假于物也嘛，自己不知道如何有用而务实的努力，问问别人撒，当然最好不要看他怎么说的，看他怎么做的，因为做的比说的务实嘛。

这种方式当然可能无法一蹴而就，毕竟不同出身的人，能傍上的人是不一样的，同样一个男生，在小城市能傍上KTV女老板，在大城市说不定能傍上女老板。但是傍上去以后要干什么才能巩固已有的胜利，以及踩在胜利的肩膀上走向下一个胜利呢？当然是努力发展共同利益，捆绑利益，最简单的就是多待在一块，日久还生情嘛，起码发展了共同的情感经历。以及看看下一个傍的对象需要什么，好好准备。当然除了这两点，也要注意为自己转化利益，该努力积累财富、权力和势力的都不要含糊。当然该睡女生男生的趁年轻睡了都ok，只要别荒废了自己现在的主顾、下一个主顾、钱权势这几点就Ok了。

那一辈子都傍不上几个怎么办？其实从和尚到洪武大帝，身份的跳跃并不会那么多嘛，以前的说法据说是只要通过六个人就能联系到世界上任何一个人，同样的，要相信这辈子值得跪的贵人并不多的，金凭二字也说明平民要到那个位置其实很近嘛，对此我们要多学习。当然我们要真做得好还得学韩信点兵多多益善的。

如果你认同一定要基于“积累钱、权、势力（社会地位，或者说人际关系叭）”这个点去努力，这种就是最有用的努力，那就对了。

然后选择什么途径实现？读书叭，毕竟领导干部的选拔也是强调从“企业、高校和科研院所、事业单位”选拔，而且学历高工资就是相同情况下工资更高、而且社会地位高，稳赚不赔的。

但是读个好大学太难了怎么办？先让自己成为外国人，然后来上清北。或者让自己成为北京人或港澳台人，再不济上海人或者省城的，不能省城的就去市中心的县区，换个好地方比努力重要呀，这很实在。上大学后再升学历要搞科研，怎么办？科研就不是读书的问题了，大多数的科研并不是几本教材、几支笔就能搞得好的，得有实验材料仪器、得有论文平台肯接受、得有项目课题发钱让你去获得实验材料仪器以及去水文章。所以这时候发现没法子了，还是得回到“傍上大佬”的路子了，只不过不一样在于，学术圈子毕竟小不少，国内搞科研体制内外总共也就400来万人，而且也就“院士、千人、长江、杰青、青千、青长、青优”这几个级别，不像党内快一亿了，公务员分成27级，毕竟是卷了几千年了，跪二十多级台阶跪得又疼、靠一辈子也不太够啊。而且科研来说主顾和下一个主顾看中的利益相对来说衡量起来更公开透明——论文的数量和评级嘛，所以力气花在怎么搞文章就ok了，这就是最有效最务实的努力。

可是论文跟什么有关？老板、课题牛，基本都ok了，实际上文章哪里是自己发的，大多不都是老师找的课题、师兄教的方法、自己打的下手么，或者是老师找的课题、自己教的方法、师弟打的下手么，或者是自己找的课题、学生做的么。没错，每个时期自己要会的东西是不一样的，当然最不要紧的就是努力，做师弟时最重要的就是大方向上找好老师，具体上叫师兄师姐多帮忙；做师兄师姐时最重要的是会压榨师弟，做老师时最重要的是会巴结好拿项目以及会压榨学生好出结果，自己的努力以及学术素养在整个学术生涯并不太重要，看看周围人大概什么水平，哪里不够补充一下就ok了，好比进了雅礼长郡的人，自己看看周围的学霸在干啥，选择性地学学，补充一下短板就行了，重要的是怎么让父亲当上省教育厅主任好让自己能保送进去。

这就是我认为的务实的努力，总得来说我对于有一套行为准则的人大体是理解尊重的，尽管我未必认可甚至可能会坚决斗争，包括但不限于陪领导睡觉、送礼、捧臭脚云云，因为毕竟会坏了生态占了别人的位子，但是如果环境已经很恶劣了，依照我的性子可能就是一走了之了，毕竟人少的好地方还是有的，我又不像屈原会一死了之像李白一样一醉了之。

3、傻逼而务实的努力

“什么样的努力才是有用的呢？”这个问题我以为是不大成立的，应该是“怎样才能让我的努力有用呢？”

如果你学了大量的教育学和物理海洋的知识，那么不妨就结合一下叭，那就是小爽老师这般。

如果你看了大量的历史和文学，那么尽管你是学哲学的胡适，也不妨从文学史的角度去呼吁一下文学改良刍议叭，论证一下为什么白话文就是要比古文好。

如果你看了大量的计算机历史和编程实际经验，那么不妨就写本可以回答Javascript为什么叫这个名字、和JAVA到底有什么关系；到底计算机能不能模拟人类世界，做出像刘慈欣《镜子》里那样的量子计算机等等问题的JAVA教材叭。

又举了一大堆例子，但我想说的是，就如同读诗并不能让外卖员送外卖更快，但是正因为读诗才能让这个外卖员不再仅仅是个外卖员；甚至有可能可以让送外卖这个行业不再仅仅是搬砖搬化肥。这其实并不是开玩笑，当初我也好奇为什么有人评价有了一些罗大佑的作品，华语流行音乐才开始被认为可以是一种艺术，而和街边吆喝哼哼唱唱不一样了。游戏本来不一定会成为艺术的，说唱本来不一定会成为艺术的，并没有什么历史必然性，而是有些人的努力发挥了作用罢了。如果暂时还不能从马克思的历史发展决定论的惯性跳脱出来，我们不妨回忆一下这句据说出自切格瓦拉的名言："我们走后，他们会给你们修学校和医院，会提高你们的工资，这不是因为他们良心发现，也不是因为他们变成了好人，而是因为我们来过。"

在我的眼里，世界其实是参差不齐的，好比一个薄薄的饼，有的领域如同插了蜡烛一样突出，有的领域就撒了芝麻一样的突出，有的领域薄得好像被拉扯一样，有的领域直接是空心的。比如相声发展得就远远不如流行音乐好，郭德纲这种人品也能做出大师风范样子，《我要上春晚》文稿的技巧远远不如评弹《莺莺操琴》的回文等等，我想如果有过登山游水的经历的人，肯定是能看出一个地方的高低。同样的，我认为从各个领域的发展水平来构建世界这个圆球的（x,y,z）坐标，真的是很容易感到世界上这么多领域的发展有如此多的不足——华语电影里还没有能拍好《三体》《镜子》的水平，华语游戏靠谱的3A游戏都没有几个，VR游戏质量比较合格的都没有几个，国内都没有几种好用的VR设备的应用，包括看电影、体育直播等等，再比如山区孩子也不大能真的通过看视频学习雅礼长郡的好课——如果说学科的教科书那岂不是更加？现在这么多故作高深用名词来构建认知壁垒的教科书，尽管国外那么多基于课程讲义而成的深入浅出的好教材——抄都抄不好、抄都懒得抄。太多了太多了，你但凡了解得多，一方面你会更明白自己还有多么无知，另一方面你也会更明白世界有多么贫瘠，有太多东西还没有被创造出来。

那么我觉得一个人做的事情，有俩事儿：给自己做的，给世界做的。给自己做的我以为就是凭着兴趣凭着性子去做就行，完全不需要任何外部标准，包括去红灯区什么的，我虽然不认同但是对于这些都是理解尊重的，只是会不认同（好比我大半夜到了红灯下还是不会闯红灯，从经济角度犯罪成本低、安全角度车少交通也安全甚至从哲学角度可以体现反叛精神，各方面看我都要闯的，但是我想了想，不闯红灯这是个习惯，等一会儿也没啥，就当培养习惯了）。对于世界的话，一方面是很实际的回报的视角，谁对我好我对谁好，赡养父母好理解、回馈祖宗所以生个娃儿延续家族，朋友老师等等，以及给我启迪的这些人们，以及一个“大众”，毕竟吃的饭穿的衣服虽然是钱买来的，但是是他们做的，所以得养成回报的习惯。另一方面就是做点开拓性工作的事业心叭，当然也是可以说基于回报，只不过回报的不是一个个人、也不是说地球妈妈这种矫情的，而是说一个行业或者说人类文明，也可以说我就是单纯的想要像历史上的名人一样建功立业青史留名，满足一下自己的虚荣心，你要是非要这么理解也是对的。但无论如何要做的便是让世界这个饼更厚一点点，而不是在那根蜡烛上一个接一个踩着别人的尸体爬上去追逐那一点烧死人的火苗，或者说“给岁月以文明”或许三体迷大概就能理解了。

如果你明白了我上文所阐述的历史观、世界观以及人生价值观。就知道在这里，没有有用的努力还是无用的努力，如果人都是要死的，那都是浪费时间，只有没那么浪费时间（真的把饼做大一点）的和更浪费时间的努力，由此区分好的和没那么好的努力。

读书是一种努力，但是读好书是有质量的努力，读差书则更可能是浪费时间，还好的是，书是可以读完的，如果你只挑某个水平线以上的书的话。

所以这种努力的要点在于，先看最好的那些书、电影、音乐等等，先认识那些最厉害的人等等，先到最好的省份、国家去等等。但尽管有先后顺序，却没有”该看不该看“的偏见，心态要兼包并蓄，什么都要看得，什么都要学得，什么都要做得，王安石朋友劝他治学不要太杂，王安石说只读经不足以知经，胡适非常同意并举出《墨子》里面有光学经济学音乐学等等知识，没有其他的知识储备是不足以读这本书的奇妙之处的。所以努力做事在心态上不要设太多限制和条条框框，毕竟大师往往就是有独到见解、发现独特而重要问题、提出独特而重要解答的那个人嘛。

然后抓住自己会做的事情里自己觉得最有意思的、最实用最重要的，尤其以前没做到过的事情，多去做，做得多做得久了也就做成了。

所以这种努力的方式总结就是三句话：得实际去做而不是耍嘴皮子；挑好的做——读最好的万卷书行最好的万里路识最好的万般人；多做——天下武功唯快不破。

这种生活倒不一定是说更西式的自由了，这是一种一直在吸收好东西、想东西、做事情的生活，其实也很普通的，我只是觉得这样的生活不卑不亢、心态轻松缓慢、碌碌而有为、尤其是一天的十来个小时是给自己而不是给别人的（比如出去旅游还得看别人能不能接受来决定我是否在车上看书，很多时间精力并不能交给自己，而是热耗散在集体中），有些我推崇的大师们是这样过的，我也觉得这样过挺好的。

4、最后

我很久不写什么杂文了，因为光想没啥用，光说也没啥用，世界上大多数人是只看结果不看思想精神的，像屈原这样投湖自尽的，按道理来说并没有申包胥哭秦救楚那样的功绩，但是反而获得了更高的历史地位，这种情况还是少见且未必公道的。后世总还是有可能会出现人来给申包胥打抱不平去diss屈原的。写东西并不能增长认识，又不能像胡适一样能拿出去做演讲，只是个记录而已，花费的时间一多我就懒得搞了。不过偶尔（以月甚至年为单位计）记录一下还是有意思的，给未来的自己或者其他人考古用呗，也不用太考虑篇幅风格忌讳等等，玩起来也还好。说到这个记录，我顺便再记录一下，我到了大三最担心的事情不再是大一大二的“志气要被钱权势等现实生活问题给压死”，而是特别特别担心“志大才疏”，最近回过头发现不怎么担心了，毕竟才疏源于不学无术嘛，骗不了别人，只有真的实际去学、去做事儿才能真的找到，但是真的学了，真的实际去做了，那确实不太需要担心没有才，甚至别人想不承认都是有点难的——要说明一个人没真本事是容易的，要抹黑说一个真干出事情的人，说他没才能那还是难的。
