一月看了几部电影，但是没有及时写文章记录，在这里尽量多写写。
# 1、罗马假日，2月初看的
看的时候，想起张小花写的《我就是妖怪》，我有点怀疑这本书是不是从这部电影取的灵感：也是公主离家出走一天，并爱上或者说邂逅了一个普通人的设定。其实很多电影游戏电视剧都有王子公主贵族叭，走出殿堂来到乡野的桥段，包括狮子王的流落异域、哈尔的移动城堡走入城镇、武庚纪走入反叛者小镇云云，但是一般只是为了让主角不要那么顺利一下子把BOSS推翻而刻意制造的困难期，顺便再刷个装备之类的，因此不会花太多篇幅，而这部电影相当于把一个蒙太奇片段讲得更完整成为一部电影，倒是能够对于创作学习者来说，如何去描绘高人重回凡心这一时期有一定的借鉴意义。

不过我看的时候并不是为这种邂逅的爱情而感动云云，反而是有种伤感，因为它就是一个成人童话故事，在我能渐渐窥得社会阶层之现状后，明白很多时候一个群体是根本感受不到另一个群体的，就好像没有人会吃饭的时候想起来农民、车夫等人劳作的场景，一想起菜市场就嫌弃农夫的脏和臭。对于自己的衣食住行等等所拥有的一切，想到谁给了这一切呢？并不是真的物物交易视角下的给予者，而是自己凭本事“购买”的罢了，感恩的只是钱。权力、消息渠道等亦如此理。我想普通人都是可以想象得到在我们日常生活中根本意识不到有一群人存在————比如垃圾回收站的工人、下水管道工云云，那么比我们更有权势财富的人，根本意识不到这个世界上原来还存在着这么多人，这种感受也是可以想象得到的。因此，实际上真的有这种仙女入凡的事情，实际情况往往是排斥嫌弃挑剔，和普通人根本互相听不懂在说什么话，互相不理解，猴子和猿见面罢了。所以它安排男主角是个本来就资深到能采访公主的记者这种身份，其实是合理的，而这也更恰恰内嵌了成人童话的哀婉。

没什么深刻主题的野心，也没什么太多好咀嚼回味的地方，包括结尾也并没有让人很惊奇什么的。不过好的地方在于，整个故事非常完整流畅，公主、主角配角等等人的行为都有很多细节作为补充，使得人物的心理和行为逻辑非常清晰，确实是适合作为教学材料来看了————也就是说中规中矩但是方正得体。
# 2、何以家为
我都很奇怪这部电影何以高分，真的是其他电影太差，廖化作先锋？这电影的剪辑经常搞割裂，话讲一半的这种，而且两场官司故意把时间线打乱，可以理解为是一种风格余味无穷，但是我依然感觉是没必要装这个B，好的电影是自己的东西足够多，让不懂的人也看得懂，让懂的人看的更多，而不是这样故意让人看不懂，使得看懂了的人就觉得“真是大有深意啊！”，我以为这样的观众也只是为了凸显优越感而搞高评，就好像刻意吹捧某种手机一样。真正来讲，我对电影评价高不高不看它设置的观影门槛，而是它本身东西多不多，好不好。

他这电影确实有让我惊奇之处，主要在于用小娃娃做演员是怎么拍出来这种效果的，我挺惊讶，想起了《忠犬八公》，这是蛮难拍的。而且此片力求真实感和厚重感，又是手持拍摄又是大量无人声片段什么的。它故事并不是很多，因此那种没什么推动剧情作用但是能传达情绪的镜头可以有很多，这是这类片子的优势叭，节奏不用像商业片那么紧张。

但是这个主角以及他的精神挺让我不舒服的。结尾呼吁穷人就不要生孩子了，可以说是控诉了穷人管生不管养给孩子带来痛苦，但是非常显然的是真实目的显然是控诉这些穷人给社会带来负担，让我想起有一些科学家呼吁政府出法案买断穷人和智商不够高以及劣势种族者的生育权，每月付一千美金然后要求穷人不要生云云。充满了傲慢和偏见。显然的这部电影下主角和那个小宝宝所遭受的并不是来自家庭的、纯粹只有恶意的、不可忍受的痛苦欺压。1、显然的他们的母亲都是非常爱子女的，并不是管生不管养的状态，而我是认识有些母亲拿着在外地务工丈夫的钱、借着在老家带孩子的名义，实际上天天在外面打牌出轨，让小孩自己在家煮方便面吃。我并不觉得这电影里的孩子们比现实中我的同龄人要悲哀。2、显然的他们还能领救济物资、他们没有遇到什么社会上的坏人。最多小宝宝经受《海蒂和爷爷》里的海蒂那样被剥夺成长期的原有归属罢了。但是现实里拐卖孩童割器官卖钱，然后让孩子们去卖惨讨钱，这种东西才是真实的，因为我小时候就差点被拐走过。3、真正悲剧的恐怕只有两个--主角的妹妹被强行嫁给大自己十来岁的男人而且过早怀孕而死，小宝宝因为母亲是偷渡来的所以只能隐姓埋名生活避免被遣返，但是这是社会形态的问题，父母把女儿嫁给别人让女儿过上更好的物质生活，在中国如此，在三毛笔下的撒哈拉沙漠也如此，偷渡而来的母亲没有足够的避孕意识而怀了孕生了子，我看到的是父母努力得让一家人活下去，而不是父母生子就是原罪。总而言之，我并没有看到有谁恶意对他们使坏，因此这种仇恨穷人父母、批判穷人父母的情绪让我非常不理解甚至怀疑别有动机**
# 3、流浪地球2
我其实很奇怪，自己和周围人的观影感受很不一样甚至是相反的。前半段什么太空电梯云云我感觉差强人意，远远谈不上周围人反映的“特效太好了”等等，感觉就是很正常的好莱坞模式，毕竟建模感比较重，镜头给的速度感和张力并没有说出人意料。反倒是俏皮的中英文谐音梗等等让我觉着这个编剧应该还是花心思、有一定审美趣味的。

而且显然的，这片子花力气之处并不在科幻元素，除了机械狗、长得像门的机器人以外，那种悬浮操纵台、AR操作工具、各种建筑奇观等等展现未来感之事物，都不怎么得见。

那么我主要看的是啥，或者说我认为导演花力气的地方在哪儿呢？剧情和人物设计。毕竟这是流浪地球1的前传，对于一个已经知道结局的故事，如何吸引人看得下去，甚至有“原来如此”之感？我感到这次剧情设计还是比较完整的。虽然有些地方节奏把握并不是很完美，怀疑有所删减，比如北京水下电站，还有联合国办事处的老头儿和女生感觉设计得很刻板印象，虽然演员演绎得还行，但角色设计的功力显然不足。但是整体剧情比较流畅，数字生命计划之争、月球危机其实对于整个流浪地球是很有帮助的，没有和数字生命计划甚至飞船派之斗争不足以体现为何非流浪地球不可，有了月球危机之应对也让人对流浪地球之克服困难之可行性有了认可。而且导演一直在憋刘德华和AI意识这个重要暗线，直到结尾许多人都迫不及待要走了，我等到它终于放出来，感到和导演有种心有灵犀————我就在等他怎么交代“月球危机是怎么爆发的”这个问题。我想从剧情上，这部片子是花了心思的。

不过看到一半我去上厕所时，发现隔壁已经睡着了，我只能苦笑看来许多人并不怎么看过三小时片子，我一看它是三小时，便知晓恐怕是想往经典片去对标了，那么以商业片的叙事节奏去预期显然是没必要的。实际上从这个角度看，他的节奏我个人认为整体上是还不错的，除了中间刘德华开始要接过吴京这个主角大棒而铺陈，正值两大危机中间这一段，叙事人物心理比较细腻，但是显然奔着紧张刺激预期来看就会嫌拖沓了。除此之外，基本上很多细节都是很让人会心一笑值得一品的，比如说月球碎片为什么砸中了悉尼歌剧院而没有砸中自由女神像，为什么五十岁以上出列的国家顺序是中俄美，为什么月球危机时全球各地人民蒙太奇中都是些没怎么听过的城市。我想这些比北京水下章鱼那让我笑出声的建模水平要有意思得多。

总的来说我还是蛮喜欢这部片子的，它胆子挺大，直接想搞成星际穿越之类的科幻片，而不是好莱坞式小孩子过家家打打杀杀的套着“科幻片”外壳的奇幻商业片。希望它能拿一些奖项荣誉叭，毕竟从中后半段来看导演的期望不太像是商业赛道的。
# 4、黑豹2
刚开始挺好，音乐很好、为瓦坎达设计的独特语言文字、服装、城市等等，让我感叹导演作为指挥官这仗打的真富裕，然而从引入海底种族开始有点拉了。族长是印度面孔，但是族人阿凡达蓝皮肤？服装上又是玛雅？让我想起古墓丽影9的古人。很多地方让我大跌眼镜————全体人类打酱油，就一个十九岁小女孩搞个钢铁侠走走过场？瓦坎达居然为了一个和自己非亲非故的人类科学家枉顾强敌？红头发女子一下水，下次出现就直接到被关押着的公主身边救出她了？女王被攻击时身边一个护卫也没有，一下子就被干死了？海底军竟然不乘胜追击一举灭国，反而希望杀母仇人和自己同盟，真·城下之盟？忽然就制造出了人形心形草？这些地方一看就晓得准备得很仓促，根本不打算说清楚，糊弄糊弄就过去了的。还好结尾没有把海底王国族长杀死，起码有了个要放下仇恨以大局为重的立意，让人物形象弧光来了个90度漂移，否则这电影我要惊得喷汽水了。

整体来说，高开低走最后回旋上来差强人意。我有点好奇黑豹一到底讲的啥了，为啥票房这么高。
