# 浪淘沙

## 总评

这是1936年的老电影，老实说我觉得现在拍估计也就只能十来二十分钟就够了，这个故事感觉撑不起一个小时这么长啊。

技术上它也有不少瑕疵，比如音乐的切换没有渐入渐出、画面有暗角云云。不过它有些表达手法放到现在也有一定借鉴意义的。
