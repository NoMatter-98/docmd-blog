# 2023年21岁生日

我向来不怎么过生日，往年都是母亲来祝一下生日快乐，去年是怎么过的已经有点忘了，好像是母亲发了个祝福消息（和小红包？），鉴于我这记性，还是有必要记一下过去几年里对我表示过关心的人，以免失去感知能力。

前年2021年大概是分团委换届那会儿，我正生气于办公室换届拉胯，然而他们给我惊喜得过了个生日，让我哭笑不得。我许的愿望是啥忘了，反正应该是很大很空的，什么世界和平之类的。

所以去年应该是母亲发了生日祝福叭。

今年YZ姐知道我之生日，遂给我准备了一些打印的照片（还挺好看），还有个日记本样式的东西，不知道一年时间写不写得完，我觉得够呛。S师兄提前送了我个索尼的降噪耳机，很好用。ZH师姐后来给了我两本漫画，看上去很好看，但是也不知道什么时候会看，反正近期在狂刷《炎拳》，早点刷完就可以早点开看了。而且YF和JH老兄带我吃了顿啥品牌的火锅来着。还是很高兴能有欢聚时光。前几天，应该是7号，睡着时忽然来电吓了一跳，是父亲打来，问我今天是什么日子，我一看是周日，支支吾吾说不会是母亲节叭，不好意思母亲节快乐云云，然后说是我今日生日快乐，吓了我一跳，然后还是母亲发了个小红包， 晚上哥哥也来了个祝福红包。大致若此叭。以后如果我小孩子问我小时候生日怎么过的，我就拿这篇文章告诉他我二十岁左右的生日就是这么过的。

——商子羽
