# 桃李劫

我觉得真的是人生必看的一部中文片子，它讲得是真的贴合我们有良心有怒气的知识分子在步入社会的故事。而快一百年了，我现在没有看到别的同样故事的片子，不论中英文。



- 开头介绍，用的字体居然是浮雕的感觉，很有意思

- 这是有声音么？1934年的片子居然不是默片？虽然没有字幕，而且这声音里杂音贼大。

- 居然有镜头追踪人物移动？而且这么稳不像手持的啊。



难道没有字幕？我觉着有志愿者的话可以配置一下字幕诶，很多地方都听不清话。然后这念台词的感觉很重啊。

- 这首歌江泽民当初做指挥表演过，是田汉词聂耳曲的《毕业歌》，原来它就是《桃李劫》的主题曲，随着电影而发行的啊，长见识了。

- 找工作这段很真实啊，现在也还是这样，不唯才而是唯亲是用

- 和上司有矛盾愤而辞职也是。

- 老婆和她上司有嫌疑也是典中典。说起来在红色时代很少见到这种家庭题材诶，1979的《瞧这一家人》就回归家庭了，果然伟光正太多，人真正日常接触最多的还是家庭生活。

- 这个配乐有点猫和老鼠那位了——老婆和上司去饭店的路上那段。

- 说起来那时候人的普通话跟现在老北京口味的北京话是完全不同诶。
- “不能忍耐的时候，不应该再忍耐。”确实是有道理的。

- 老婆生孩子了也不准请假，必须上班。——忽然意识到，现在好像不能拍这种电影了吧。忽然感到一种电影以外的悲哀。
