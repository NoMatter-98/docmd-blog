**T8.**m阶B树

> B树各结点的平衡因子都是0，最下面一层是铺平的。

> m阶是说最多有m个children，B-树不是二叉树

> **关键字(key)**non-leaf node如果有k个children，那么它必须有k-1个关键字，for what?

> **
> 

> 
> Each internal node's keys act as separation values which divide its subtrees. For example, if an internal node has 3 child nodes (or subtrees) then it must have 2 keys: *a*1 and *a*2. All values in the leftmost subtree will be less than *a*1, all values in the middle subtree will be between *a*1 and *a*2, and all values in the rightmost subtree will be greater than *a*2.

**T34.**奈奎斯特准则,QAM调制技术

> 

> 
> M进制码元：单位时长里的信号可以有M种高度，也就是**M个离散电平数目**，实际上携带的是log2M个bit的信息。

> 
> - 
> 波特baud实际上是单位时间传输码元的个数，（其实也是调制速率）乘以log2M后是单位时间传输的比特数bps

> 
> - 
> 带宽有两个：一个模拟信号里，单位是hz，仅仅是输入信号的最高最低频率差值；另一个是数字信号里，bps，

> 
> - 
> 栋哥的音频里有说过，研究生时候还要专门来学香农定理的，所以要搞清楚现阶段是很麻烦不必要的。

> 
> - 
> 奈氏准则：带宽受限、无早生，传输速率上限应该选用2W Baud或者2Wlog2M bps ，W就是模拟信号的带宽。

> 
> - 
> 调制：数据变成模拟信号的过程。QAM，就是又改相位，每种相位下又改幅度（我也不晓得为啥不选相位下改频率的方式），但总之一个码元可以有更多种变化了，所以是4种相位乘以4种振幅=16

> 
> - 
> 香农定理：带宽受限、有噪声。选择的上限应该选Wlog2(1+S/N)，S和N是信号、噪声俩的功率。信噪比如果给多少多少dB，它等于10* log10(S/N)，后者的是功率比，所以是把dB前的数先除以10，再10的相应次方就行了

T37. 介质访问控制之CSMA/CD  

> 

> 介质访问控制。目的是防止局域网内共用信道时产生冲突。——也就是要分配信道。有静态分配、动态分配。动态分配里有轮询访问和随机访问，
> - CSMA：Carrier Sense Multiple Access 发送帧前，要侦听介质是否空闲。MA意味着常在总线型网络。
> - CSMA/CD： collision detection发送时也一边监听着。一般是有线局域网中。半双工网络。
> - 为了避免传播时延τ对CS的影响，要控制帧的大小。帧的传输时延=**帧长/数据传输速率>=2τ**，为什么争用期/冲突窗口是2τ？见https://www.youtube.com/watch?v=-LD2Qv5Jj78&list=PLjAs5kw1NNs2hsblGz3WjBHs1EO8KcuZs&index=33 但是btw，以太网规定帧长是64B-1518B，更小的都算作冲突产生的无效帧。
> - 网络传输速度的Gbps的G是十进制，而存储的GB/s是二进制的。
> - 什么时候重传？——截断二进制指数规避算法。规避时间为2τ，k=[重传次数，10]，r=[0,1,2,,,,2的k次方-1]重传所需要规避或者推迟的时间为2r τ选一个。重传次数到16时就放弃。——实验失败只能接受16次。

> [TCP传输中的拥塞控制和流量控制是两个不同的机制。流量控制是端到端的控制，例如A通过网络给B发数据，A发送的太快导致B没法接收（B缓冲窗口过小或者处理过慢），这时候的控制就是流量控制，原理是通过滑动窗口的大小改变来实现](https://blog.csdn.net/weixin_39731083/article/details/81813774)[1](https://blog.csdn.net/weixin_39731083/article/details/81813774). [拥塞控制是作用于网络的，它是防止过多的数据注入到网络中，避免出现网络负载过大的情况。常用的方法就是：（1）慢开始、拥塞避免（2）快重传、快恢复](https://zhuanlan.zhihu.com/p/37379780)[2](https://zhuanlan.zhihu.com/p/37379780).

> [举个例子，假设你正在下载一个文件，你的计算机和服务器之间有一个路由器。如果路由器缓存区满了，那么路由器就会丢弃一些数据包。这时候拥塞控制就会起作用，减少数据包的发送速率，以便路由器能够处理更多的数据包。而流量控制则是为了防止接收方来不及接收数据而产生的问题。例如，如果你正在下载一个文件，但是你的计算机处理速度太慢，那么发送方就需要减少发送速率以便接收方能够处理更多的数据包](https://blog.csdn.net/weixin_39731083/article/details/81813774)[1](https://blog.csdn.net/weixin_39731083/article/details/81813774).

> 也就是说两种stuck产生原因不同，一个是接收方能力不足（也可以说传的太快了），一个是网络中转发能力不足（也可以说传得太快了）

T47.路由相关

> 

> 子网划分。这题甚至没有牵涉子网掩码，只是在点分十进制的4个数后面/那个数，是0-32.但是子网IP地址一般选主机地址全为0的。
> - 子网掩码就是A.B.C.D/N中，二进制里前面N位全部为1，其余全部为0形成的点分十进制数。
> - 到互联网的路由为默认路由或缺省路由，0.0.0.0，子网掩码也是0.0.0.0
> - 路由聚合技术？就是要减少其他路由表项的数目，从而表现得A.B.C.D/N，子网掩码a.b.c.d。把N减少，重新构建一个网络段的网络号A1.B1.C1.D1/N1 子网掩码a1.b1.c1.d1
