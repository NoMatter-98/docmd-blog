# 第一次焊锡，DIY小车车
从淘宝买了套件、工具包、电动螺丝刀来，体验一下焊接电路板的基本操作。基本上就按照店家的这个PDF教程来走就行了。
[5 循迹小车电子教程](/assets/images/wp-uploads/2023/02/5-循迹小车电子教程.pdf)
总共花了可能五到七个小时。1、焊接。**我主要参考这个视频：[电烙铁焊接第一课--吴老师](https://www.bilibili.com/video/BV1S54y1r7oK/?spm_id_from=trigger_reload&vd_source=d3bd503d8671f15930b06bd62275329b)**不过没有万用表，我也不知道怎么检测焊得好不好。
2、剥线。**看了某个帖子才晓得，拿斜口钳压一圈，然后拔出来就剥线了。

最后的结果差强人意，本来这个车子是要能够在黑色轨道里跑的，结果不晓得为啥，两个轮子只能同时动一边，一边停下来时另一边才能转动，不晓得是电路板出了问题还是我焊接出了问题。不过此番熟悉一下焊接工具、常见的74系列IC后，发觉并不是很难，可以说为下一步焊接TD4这个CPU做做预热准备吧。
