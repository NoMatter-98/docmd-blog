# 世界上到底有多少本书、多少篇论文？

## 前言：

​	研究这些个问题基本纯属我的兴趣。其次是因为在思考其他问题时关联到这儿的。我觉着做学问首先是提出有价值的问题，齐次才是得出有价值的答案。

​	本科做科研的时候所谓的老师和师兄们都说要多看文献。我的习惯是研究一个课题时，先把市面上所有能搜罗到的相关主题的文献全部下载下来，研究历史梳理一下，研究机构梳理一下，获得一个基本常识，我以为这是基本要做到的。尽管大量的知识根本就没有上书本、更没有上网络，但不可否认，大多常识性东西都归结在书本文字载体和自己动手实践中，相比之下口耳心授、podcast和视频都还处于补充性的低位。

## 正文

### 1、世界上到底有多少本书

​	（1）世界到底有多少书？维基百科“图书”词条中是这么说的[1]：2010年，谷歌公司估计，从印刷术发明至今，大概出版了**一亿三千万**本不同書名的书籍。当然他对“书”有详尽的规定，包括页码、ISBN号什么的，这些是一个补充性知识。<font color="red">而且这个数据有点滞后了，有时间我自己或者有好奇的学术志愿者可以帮忙忙考证一下。</font>我相对而言倒不太关注多少页码才能叫一本书云云的规定，我更关注从数量这个概念去深入提问：

（2）中国到底有多少书？有一篇文章叫：[2]《中国五千年的历史，出版了多少种图书？数据来了！》我看他的数据和我在其他地方看的数据大差不差，倒是没有一一考证。我挑出几个数据来看看：

- **1912年以前，中国书籍出版量181755部，不到20万部。**明朝以前一个朝代不超过2万部，**平均算下来一年也就100本这个量级。**这个产量其实也就是现在电影的水平：[3]2021年中国生产科教、纪录、动画和特种影片175部，电视剧194部6736集。当然这个书籍的量，不考虑失传的以及不被官方收录统计进来的，就好像现在古代写得账簿日记、今天人自己录的vlog，都没有被收录到上述的这个数据中去，那是一个意思。

![image-20230904094516194](./image-20230904094516194.png)

- **民国以来中国有出版多少新书？八九百万。**1921-1949近四十年出版12万本，**平均一年三千多**；建国后**文革的前五年大概一年三千本上下**，**其他年份大体都是一万本加减4千本。**改革开放后就大幅提升，但是最近五年有到顶反折，过去三年以及这个趋势看未来三年，差不多**一年新出版20万本**加减五万这个水平。
- 古往今来中国这些书中，和做学问相关的领域有多少书？古代的20万部里，跟自然科学相关的不超过2万本。<font color="red">1912年以后的我倒是还没有查证，有时间我自己或者有好奇的学术志愿者可以帮忙忙考证一下。</font>

​	这么看来，书是可以遍历完的。但是做学术现在大伙儿都电子化查阅了，所以我特别关心电子化的书有多少。

(3)世界上有多少电子化的出版图书？这里我要介绍一下开源的library genesis、sci-hub这几个耳熟能详的数据库。

- library Genies可以说是母体，它把所有书分成了fiction,non-fiction,和scientific articles三类。其中fiction272万本（https://libgen.rs/fiction/repository_torrent/）non-fiction378万本（https://libgen.rs/repository_torrent/），这俩大概70多TB。
- 至于scientific articles部分，其实和大名鼎鼎的sci-hub差不多。sci-hub本来是一个哈萨克斯坦的女研究生2011年搞的，一开始它的数据是借Libgen这个母体的服务器，2014年以后用自己服务器存这些文件，但是到现在，sci-hub和libgen的scitific articles的部分体量是一样的，基本上可以互通。这部分也是搞科研要用的paper，总共到2021年停止更新为止有8千多万个papers，大概是80多TB。再其中，标注为计算机领域的papers有270多万份，我依此估计有2TB多，<font color="red">但是不知道怎么download下来计算机领域的，libgen论坛有人讨论“如何下载全部的中文书籍”“如何只下载某个领域的书籍”，但是我还不大会用sql数据库相关知识。</font>

- 当然还有，z-library本来是母体libgen的镜像，像这些数据库常常都是有好多镜像网站而且过一段时间要换的，所以这并不奇怪，libgen就有libgen.rs版本和libgen.li等等版本，其中.li版本是最全的，多包括了一些杂志等等，具体我还没有详细考证，据说多出的这部分使得整体数据库涨了100TB左右。**实际上搞电子书开源化，基本都是这一批数据，而且也就这一小批人**，比如说zlib和古腾堡计划的创立者也是有关系的。

所以说，基于library genesis，收录的传统书大概600多万本，70来TB；科研文章8千多万份，80多TB。



### 2、世界上到底有多少论文？

精确的总数多少我查不到。<font color="red">有时间我自己或者有好奇的学术志愿者可以帮忙忙考证一下。</font>

- 2010年以前有多少篇？。估摸的数字里，有研究说2010年以前大概是**5千万份papers**，但是他以及他的前人的研究方法称不上多么精细和高明，无非是统计一下有多少期刊、有多少论文，然后用excel水平的软件拟合一下就出来了。我没看这篇文章之前，想的办法也是最粗糙的方法——去遍历所有的期刊，然后从里面去数。但是这个最权威最全的统计期刊数量的数据库Ulrich’s Periodicals Directory (乌利希国际期刊指南)都已经是1932年开始出版的了，20世纪之前的期刊很多恐怕没有收录，像下面第一个图是预测每年有多少期刊，他设置1726年为零点，说白了不是一个统计结果，是个线性拟合的结果，基于此做的paper数量的模型那就更不见得精细了——这就是功夫不花在材料上，问题得不到什么有质量的答案的，这个在史学研究上都是共识，反而在很多其他所谓自然科学领域不见得那么重视，乐。

![image-20230904120348078](./image-20230904120348078.png)

![image-20230904120412601](./image-20230904120412601.png)

​	那为啥早期的期刊数目不好统计呢？只能说早期学术期刊出版不像现在正规，根据维基百科“academic publishing”这个词条，最早的论文出版是1665年的Journal des scavans。其实学术作品无非是自己研究出来了问题的答案，本不一定是要写论文，古代往往是写专著，毕竟要讲清楚一个问题往往牵涉很多小问题，而不是现在的水论文一篇就讲一个问题，好比如达尔文写东西也不是写一点发一点，而是写成一本书反复修改再发出来。我猜想当初恐怕是争首发、以及搞学术的人渐渐多起来才有了办期刊或者说报纸的必要性，因为据维基里说，Robert K. Merton研究过17世纪92%的同时发现的成果最终都以争议告终，到了18世纪就下降到72%，19世纪后半期到59%，20世纪上半期是33%，虽然我不明白他这个研究到底怎么来的，但是我觉着道理上讲得通，为了抢首发，所以稍微有一点点小发现就先发出来，好比以前写小说是写好全本再出版，后来渐渐有点像金庸再报刊上连载了。另外也有交流的必要，好比现在IT产品都喜欢开发布会，其实我觉着未必是给消费者开的，可能就是给同行秀肌肉用的。

- 2010年以后就都好查到了，近几年都是每年5百万左右而且稳步增加，所以加起来，**学术界能够统计到Ulrich’s Periodicals Directory (乌利希国际期刊指南)里头的论文这350多年大概就刚好1亿篇论文左右**，误差上下不大可能超过一千万。

但是有大量的论文根本不会发表到期刊，而是学位论文，考试写的语文作文不见得会在报纸发表，更不大可能收录为“作品”，这是一个道理。所以我们要把这些实验室作业也算进论文的话，那得另算了。不过唐朝有那么多诗人，也就编了个《唐诗三百首》，这些家庭作业在正儿八经搞科研时，不一定很值得用。

但是毕竟有比没有要好，尤其是硕士博士的论文，我的经验来看它研究的结果价值未必很高，但是研究过程中设计的人、材料等等参考价值还是不少的。<font color="red">有时间还是要盘点一下中文的所有论文数据库（尤其是硕士博士的学位论文）</font>



### 3、最重要的图书和论文有多少？

​	梁文道在《开卷八分钟》有引用过一句话“书读完了”，还有一个人说过一句话大意是“不可能读完所有的作品，但永远可以读完最重要的作品”（<font color="red">有时间考证一下是谁说的这两句话</font>）实际上我自己经验里，一个领域里看看top100就差不多入门了。

​	实际上这上亿的图书和上亿的论文里面，电子化的收录主要在anna's achieve项目（https://tw.annas-archive.org/）中有罗列，其中电子化的zlib，90TB左右，但是最精化的是早期的200万份文件（确实差不多是百里取一），**7TB左右**，因为他们后面做备份的时候也没有太仔细地一一做重复文件的剔除等等工作。目前他们主要的工作，我看起来主要是接着做备份已经开源的书籍、以及做书籍封面。

​	另外，就如同看电影top就去按照豆瓣top100/250，IMDB top，等等一样，看书也是，先挑一个榜单看着，看完一两个榜单以后基本上大的知识了解得也就差不多，可以按照自己的兴趣去找研究内容做学术了。书本我目前就是豆瓣top100，历史类公认的好书并不多，按照知乎或者某老师（我忘了）推荐的书单来看就行，计算机得到公认的好书和好课程也不多，我暂时看到比较全的有：https://csdiy.wiki/%E5%A5%BD%E4%B9%A6%E6%8E%A8%E8%8D%90/，反正不超过100本。计算机的top论文，我暂时看到有这个，大概500篇：https://jeffhuang.com/best_paper_awards/。<font color="red">至于生物，除了神经科学做脑机接口方面以外，兴趣有所下降，竟没有搜罗什么榜，有机会再自己考证或者留给大伙儿了。</font>



## 收尾

​	本文总结，估计现存的图书一两亿本，收录的有国际性的论文1亿篇。

​	为啥刚写好就要发表：之前我是打算研究性的话题，要沉淀一年时间后再写文章，以评估这个话题是否有写文章的价值、以及用一年时间沉淀写作的材料，比如年初换手机屏幕，我现在看来就觉着光这一个点其实不见得有太多研究价值。但是我现在改变想法是因为，可以先写一个初稿发表出来，标注出我现在还研究不到位的地方，说不定有讨论价值，等一年后再重新整理一次，说不定就兼顾了实时性和重要性了。
