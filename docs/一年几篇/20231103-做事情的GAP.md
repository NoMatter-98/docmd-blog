# 20231103-做事情的GAP
我发现做事情讲究个一鼓作气。
折腾一个环境配置，只需要有电脑、有网络、有参考资料，弄个把小时就能完成，就算有各种问题，大概5小时以内总可以的。而所谓的mind-flow的为状态下三五个小时做一件事并不难。一天就能解决。
但是，如果遇到网络不可以，要县解决网络，发现存储空间不够要腾挪一些空间，要安装其他前置环境云云，可能总时间在10小时以内，也就是2口气可以完成，可往往并不是2天就能解决，而是会Gap1天，也就是要3天才能完成。再加上如果买东西要快递，做完以后要整理总结等等，3天是必须要的。
如果一个事情的复杂程度可以写在流程图技术路线(roadmap)而还是要自己一个人解决，那3口气完成就不是3天，也不是6天了，而是一周起步两周算快。

所以我发现做事情预留时间，我之前发现跨考也好出国准备也好，各种人生大事情，最好是提前2年开始准备，这样从收集资料、开始行动、勘查环境、联合伙伴等等才能做得相对周到一些，才比较有把握。或许正是出此原因————做事情按照总时长是一回事儿，还要算要几个步骤，每个步骤之间可能会有GAP。这样才能估算到底要多久准备时间。
