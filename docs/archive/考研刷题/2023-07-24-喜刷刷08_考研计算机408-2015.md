## 解疑
T6

- [x] 最小生成树是什么最小？   哈夫曼树那样“根结点的权值”最小嘛？  还是带权路径最小？为什么是边权？

边权之和最小。不是。不是。就是边权。
- [x] Kruskal算法和Prim算法：

Kruskal 算法是按权值选边，若选边后不形成回路,则保留作为一条边,若形成回路则

除去。Prim 算法是每次从当前的二叉树节点向外延伸的，选择权值最小的边。

T26

- [x] 死锁检测是啥措施？死锁预防？

死锁预防——互斥（全部资源都能共享）、主动释放（强行释放）、请求并保持（预先静态分配法——没有申请到全部资源就不运行）、循环等待链（顺序资源分配法——只能申请更高编号的资源，避免申请的资源已经被别人占了的情况）

死锁避免——安全一定不会死锁，不安全可能会死锁。银行家算法——超过声明最大需求，不分配、已有的不能满足最大声明，也不分配（导致不安全状态的，不分配）

死锁检测和解除在分配资源时啥都不管，只是可以检测是否死锁，死锁以后直接剥脱资源撤销进程或者强行进程撤销作为解除死锁的手段。
