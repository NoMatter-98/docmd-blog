 再下一步是如何用github，如果是直接从自己的库上面download代码下来就不用另外设置上传网址了：

```
git clone 网址
（git remote -v可以查看fetch和push的网址）

git push -u origin main
然后要输入github的帐号密码就行
```



```
如果是fork后download下来的，就要切换一下：git remote add upstream 网址）
git checkout -b joger 网址  //新建分支并切换到那儿
git push -u origin joger    //push并指定源和分支 
然后再上自己的分支里面pull requests.
```
