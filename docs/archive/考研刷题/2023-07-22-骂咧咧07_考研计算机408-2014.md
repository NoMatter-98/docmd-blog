T18

- [x] 下地址字段法（断定法）？？——《组成原理》P232，说白了就是微指令中直接包涵下一个地址
- [x] 指令和微指令程序/微程序和微指令的关系？——一条指令，也是一个微程序，对应好几条（不是好几种）微指令。微指令系统中要包括指令包涵的指令们+公共微程序对应的指令们，所以是32*4+2=130条，所以要8bit

T21

- [x] 端口和接口的含义以及异同？——《组成原理》P294  IO接口是IO控制器，包括各种寄存器（其中能直接被CPU访问的成为IO端口）以及各种控制逻辑，另外正好理解IO总线的数据线（数据，以及反馈IO接口信息）、地址线、控制线（后二者是CPU发给IO的）
- [x] 独立编址/统一编址？——同上。统一是指与内存存储器一起编址，所以只要访存指令就可以访问IO端口；独立编址是分开编址，所以要IO指令才能访问IO端口。

T23

- [x] 静态优先数调度  是啥？——处理机调度有好几种：FCFS、SJF（短作业优先）、高响应比优先、优先级调度（静态是进程创建时就定好优先级了，动态是指优先级会变化）
- [x] 不会导致饥饿现象的处理机调度方式有哪些？——FCFS、高相应比、时间片轮转。              
- [x] 为什么非抢占式短作业优先也饥饿——进程不是排好队上公交车，那是FCFS，更像是揽工，一堆人在这儿，每次车来只招一个人，招的时候只按照身高招最矮的。

T25

- [x] 哪些是用户态可以执行/发生/完成的操作，哪些是内核态才可以执行/发生/完成的操作

只能先收集了，书本《操作系统》P19没讲这么多——用户态执行的：trap指令、跳转指令、压栈指令；内核态执行的： 关中断、中断返回等特权指令

T27

- [x] 一个簇是不是就是一个盘块？——不是，《组成系统》P246，一个簇可能是几个盘块组成的。但主要是按照簇来分配文件的空间还是按照块来分配而已。有种说法是win系统一般按照cluster分配，linux系统一般按照block分配。
- [x] 什么叫位图所需的簇的数？——意思是问这个位图（换个，比如页表，就好理解了）占多大空间，需要多少簇的空间才够存

T28

- [x] 交换区  是啥？？——忘了是哪一页了，讲内存和外存调用时候说，交换区就是内存传回外存的一个放置区。

T30（完全没看懂题）

- [x] 分配一个还是两个页框给“这个进程”  和进程调度——“哪个进程先被服务，哪个进程后被服务”，有关系嘛？ 

进程和作业的调度算法不同于页面置换算法，前者是考虑把哪个进程/作业放进来分配资源；后者是考虑把哪个页框淘汰出去。

前者有FCFS、时间片轮转、SJB、高响应比算法、优先级算法、队列＊*算法这几种。

后者就FIFO、OPT、LRU还有CLOCK这四种算法。

- [x] 怎么就会出现Belady现象呢？——看例子叭，只是一种可能

- [x] 调制速率  是啥？——数据变模拟信号为调制，数据变数字信号为编码

T38

- [x] 什么叫 “接受窗口为10KB的确认段”？——应该是说确认段里声明了接受窗口rwnd为10KB
总共有接受方设置的接受窗口、发送方设置的发送窗口（min{rwnd,cwnd}）和拥塞窗口。
- [x] MSS  是啥？——TCP中数据部分的最大值（MTU是数据链路帧中数据部分（也就是IP分组）的最大值）
- [x] 拥塞窗口为8KB 是啥意思？——预计拥塞为发送8KB的，发送窗口（min{rwnd,cwnd}）

[x] 这题是在考那个拥塞以后除以一半，然后又渐渐上调的那个嘛？——是的，计算机网络中TCP协议之拥塞控制。

1、拥塞窗口cwnd是发送方自己设置的。单位是MSS

2、慢开始（拥塞窗口为1-2-4-8，直到超过ssthresh慢开始门槛slow start threshold应该是）-->拥塞避免算法（从ssthresh开始作为cwnd，每次加一）--->快恢复（遇到拥塞，ssthresh设置为拥塞的一半，并从这里开始拥塞避免算法）

T40

- [x] PPP和UDP是干啥的？

PPPoE——猫用的协议，主要是用来连接两个点（也就是说这个网里只有两个设备）。

UDP——无连接不可靠传输——只有俩功能：多路复用和数据检错（不会选择重传，所以不可靠）——基于它可以有DNS等传小文件的协议。

IP、MAC协议也是无连接不可靠的
