# 2012
## 感受

- 这卷子我是不是做过？有好几道题都一眼看出答案或者解法从而直接略过的，速度比前一张快了不少。
- 我下载的这套真题实在是错误频出，总是要和知乎上的校对才行。

20230815

前几日去了趟南京和苏州，期间没有精力，而且当着同伴的面不大好去做卷子（毕竟我就看看闲书也都可能被认为卷，尽管其实对我来说刷卷子已经渐渐从繁重的工作开始轻量化了很多，估计过段时间，就会和看电影查资料梳理背景知识的心力消耗差不多了）

回来后今日睡大觉，百日只有三小时左右清醒的，吃点东西然后趁着苏州之行的余波看了看评弹与《牡丹亭》，甚是喜爱。

晚上就一点点时间，也无什么心力，还是抄了抄卷子的答案以完结之。这让我想起据说是冯唐的名言——写小说的要诀无非三点：一是尽早动笔，二是让屁股和凳子建立亲密关系，三是该完结就完结。也就是不要怕烂尾不要钻牛角尖，完成重于完美，其实刷卷子做学术也是这样，胡适说做学问“勤谨和缓”的谨，是一点都不马虎，一个字都不要错这种，还举了例子说什么oaks抄错成了oats云云。但是老实说绝大多数人是只看结果的，而他们看结果，从其角度出发，所以很多时候并不那么重视质而更重视量，比如周杰伦的专辑量就是大很多，MV也多，量大管饱，在豆瓣上就专辑而论，陶周王林四人专辑53张专辑的top10里头，陶喆的蓝专虽然是第一，他的三张专都是前十，但是评价人数是2W2W5W这个体量，林俊杰当初令我震惊的《与自己对话》（还是《和自己对话》来着？）评价量最惨只有6K多人，而周杰伦的评价量都是8W10W十多万，结果连周杰伦首专《JAY》这种当初在大陆根本就没怎么卖出过，当初不可能有几个人听的专辑，居然也能被考古到评价量8W多，被过誉到排名进前五。所以可以看到在有些时候确实不是说“慢工出细活”而是要“天下武功唯快不破”，因为数量多了就会互相带动起来，practice makes perfect嘛，practice意味着one more time而不是only one chance。

所以我今天怎么着也得把这个完结了。
