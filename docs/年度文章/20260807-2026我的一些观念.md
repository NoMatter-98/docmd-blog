一：旧闻新识。

世界观上，十阶级观，我还是认可的，但不同的是，我2024遍历常宁、顺德、游泰国、杭州、北京、东莞、游香港。2025在新加坡、游马来西亚，2026新开广州。 足证阶层分别，是世界级现象，常宁、广州、新加坡的清洁工，都是苦。人之处境上，地域区别到一定程度————到杭州程度，就已经区别没那么大了。  还是钱、权、社会地位三要素区别，远远大于所谓城市市民身份。

历史观上，我这两三年读了些《国史大纲》《人类简史》之类，历史观更加整体性了，这一方面，博学还是颇有效益。但是上次没有细讲未来观，这里按下不表，第二部分再说。

玩学观上，我之前认同玩而优则学，但那时候更多是为了论证：要达到一个难的目标，我们可以把陡峭的学习曲线变成多梯，或者把直接解决问题变成先解决相关小问题，农村包围城市。   但是这三年下来我虽然还认同玩物不丧志而是养性情，但颇为不认同借此来逃避、打间接球的态度。  现在我看来，要学某个难的东西，就先直接学他；要解决难的问题，就先直接解决他，包括与人相处也好，做事也好，研究方向也好，概而言之就是打直球。   因为世事变化无常，搞曲线救国可能所谓三步走，但你完成第一步的时候，可能情况就已经变化了。   这两年AI发展日新月异，我们这个年龄的人的处境也变化很快，以前我们知道政治眼前一寸皆是迷雾，现在看来我们个人处境又何尝不是？恐怕确定未来一两年的情况就不错了。所以玩是态度，但不能用来名为曲线救国，实在逃避拖延。
此外，心性上务要讲求纯朴天真善良，例如扬帆这种烂漫，不贤人在意一些人看法，可以赢得真正贤人之间的赞赏，有何不可？

工作的意义： 我虽然也认同“答疑解惑”之说，但老实说，我最近的想法的确在于：工作首要是为了有收入，实现第一第二财务自由加速度，第二是让自己作息、场所等生活状态稳定，第三是积累技术和抱团人脉，为后续做更大事业铺垫。  至于解决问题————在现在后DeepResearch时代，想要获得答案，真相，也就是解决“知”的问题，意义感大大消失了，但是“行”的问题，AI并不能解决，比如说你想做人类永生，知不知道或者说猜的准不准根本不重要，做不做得到才是重点。

二、过去三年之经历与思想转变
1.四个时代
后考研时代，2023年9月以后，我在望月公寓待了几个月，实在昏暗，唯一可记者乃常识关自我禁闭，看人身体多久出问题，人精神多久出问题之实验。   12月考完后，本想在杭州找工作，然父亲来电说母亲在长沙看病，让我速回，于是回来。当时感到母亲骤衰老，真是四十多岁貌了。  在常宁大约一个月，期间拜访一位小学校长，又查出痔疮，至今仍不时发作，大约就是23年下半年自我禁闭实验的产物。不久到顺德处理房产出租，顺便第一次裸考雅思尝试，再并和哥哥去泰国出游，稍试出国之体验，再回常宁过年。  过完年大约一周后来杭州找工作，大约两周，小辉老表知道便让我住其家。 3月中出成绩，联系老师，在常宁的小学校长认识一位中科院教授，是常宁老乡，于是借这根线联系到中科院计算所老师，于是我去一趟北京以为是一场面试（当时北京清晨的印象至今历历在目）。  
北京时代，不料卜老师当天便留我在所里实习，于是在西北旺黑龙潭路冷泉村租住，在所里（不久从北三环搬到北五环环保园）待了四个月。期间出成绩、调剂不成等，皆不赘述。6月初告假在家准备一周还是两周雅思，在人大继续教育学院考雅思，几日后出成绩。于是找得老师开推荐信，写各种材料，7月中旬，回杭州开推荐信、投留学申请，只投了两家：24秋的港城莞和25春的新加坡国立大学，专业都是计算机科学与技术。 8月费3周还是4周完成科目二到科目四拿证的驾照。8月10号左右拿到了港城莞的offer，因此月底去东莞报道。  
东莞时代，九月无言，十月国庆期间找教培工作，于是去到小机构开始兼职，不久新东方回头重录我兼职，于是渐渐又卸下小机构专做新东方。十月还是十一月中旬忽然又收到新加坡国立大学的offer————直到2026的今天，我还不敢说此究竟是福是祸。  总之，我既感天命在此，遂退学、辞职、告别等，包括去新加坡前学费、手续、体检，诸多事物不一而足。 于2025年1月5日（应该没记错）离开东莞，来到新加坡。
新加坡2025时代，一月初住之地，一群舍友虽然拥挤，倒也热闹，想写写公众号之类，然而并无波澜。3月被住建局上门，于是换住处，从此甚是孤寂，外加风寒，然其实主要在于学费生活费压力、找兼职不得之压力、学业之压力、实验室之压力，于是颇为失意而至于自暴自弃也。五月后的暑假为刷满365日出境记录而在新加坡，至于八月，做各种计算机的尝试。然而找实验室也最终告失败，于是心灰意冷，准备就上上学看看书等这段日子过去再说。  唯一可言说者在9月后随李然去Bible Church有朋友可交流。 再者偶尔在浙大新加坡校友会可交流。 再者是10月11月的新舍友来，于是逐渐有点活人感。   12月初期末考试完，报名了江苏江阴市政府一活动，于是先在广州顺德小逛，去到江苏先在泰州两日，再江阴三四日，再南京一晚，杭州几日（又在小辉老表处，一年不见他已经再婚了），上海一日，回常宁两周。————此一月之记忆，犹新！那种异世界穿越回来，见到诸人的不真实感，恍惚也。
新加坡2026时代，二去新加坡，此番则只抱持涵养身心，顺利毕业，不想其他————然而正是这段时间，“两个世界”的全新世界观，等各种哲思，是自2022以来之新盛。  每日就是读读《红楼》，写写作业而已。然而在新加坡简历投出越百份始终找不到实习，可知山中不知岁月，山下换了人间，国内与新加坡之就业市场，已与23年24年不可同日而语。本来三月份想换租房到年底，然房东强以过期合同让我再留两月，北京时代扯皮问题又来，于是我索性不留新加坡了，所幸五月初找到接受导师，于是5月11日左右回到杭州。找暑期实习约40份简历，得笔试面试累积10余次，都不可得，而zh老表给我内推，遂6月20日到广州阿里灵犀互娱处开始第一份互联网厂实习，至今8月7日，已一月有余。


2.未来观：  
LLM的新AI时代，让诸多我以为下辈子才见得到的事情，甚至科幻场景，都可以仔细思考，当代可见了。
GPT3.5以来三年多，AI Coding的从无，到chatgpt对话给百行代码，到能下载.py文件，到能够在其自身sandbox里面运行测试通过后下载三四个file，到能安装在本地read write file的claude code vscode插件，到gemini cli，到codex,claudecode,workbuddy,Qoderwork这种本地Agent，消解掉了许多工作、钻研细节的意义感————天下武功唯快不破，还有什么hard working的意义呢？

文明之未来。  
我在2022年时候，曾经想过文明的关键一役：未来人类的去生物化————类似《尼尔机械纪元》的装义肢、逐渐阿尔特斯之船，到最终人脑也芯片化。以及人工智能机器人的生命化（电影《I,Robot》），最终机器人AI掌握地球的支配权。这是本次人类文明的下阶段要义————星际殖民这些恐怕都没那么快到来。 而今天，依我看这不是100年的未来，主流已经认为AGI五年左右就能实现，而通用人形机器人或者某种形式的机器人，即使许多人不看好十年内出成果，但30年内恐怕都太保守，十年前我们以为机器人警察恐怕起码五十年后，然而2026的今天已经有机器人警察而非电子监控电子警察上路了。至于人造生命与脑机接口，恐怕30年内技术早已迭代出来，只是政策规范是否能释放其潜力罢了。      人工智能这三年多的大爆发，让我理解到资金、人才、舆论、地缘政治等给科技发展的极大助力，某种程度来说恐怕也是相当宝贵的见闻经验了。   
因此可以逆料得到，（1）十年内AGI时代，二十年内，通用型机器人时代，即将到来，当初我心想，如果这是一台洪荒巨兽，那这把科技利刃宁可让我掌握而不敢假手于人。 （2） 再往后三五十年，癌症、人造生命等人类不论信息意义上还是生物意义上永生都完全开始可能了。  于是人类永生以后的新命题————万神殿之问也会到来。 （3）可控核聚变目前已经有小型商业产品了，二十年后恐怕已成熟，三五十年后也可能成为主导能源。（4）星际殖民恐怕在三十年内即将发生。 （5）人类的脑机化、义肢化，技术上未必多难迭代出来，但没有外星人、人工智能机器人的生存恐惧挑战，或者世界大战的军备竞赛需求，恐怕不容易解锁这支技能树。

战争之未来。  
更早在初一时代，我就和老庄说过，过去一百年，发生了两次世界大战，那么未来三百年内难道一次世界大战都不会发生？ 中国历史上焉有三百年的太平？  不论是人与人的世界大战，还是人与机器的世界大战，有不小概率是全面核武器的战争，这件事我最近两年有量化，全球超过百万人口的城市只有五六百，但是已经占据了最重要的20亿人口，而现在的核弹头五千发，包括储备量的话一万多发，所以确实很可能一场核战争，人类确实有可能彻底灭绝，即使没有灭绝，说什么还会再回来，但那种设想是建立在人类是最具智慧、合作的物种的前提上，但恐怕未必如此了，人类秩序崩塌的重建未必能比硅基生物快，有可能一旦被超过就是彻底的被支配命运了。

中国的未来。 初中时候我就已经算过，GDP上超越美国无非是2030年代的事情罢了，随着我上本科，了解到这些顶级智囊、科技人才后，中国全方面科研发展已经不可遏制。所谓的基础科学没有中国人，但时人没有看到各种基础学科世界奥赛中国，或者更泛泛而说，华人，已经屡屡不鲜见。从八零后开始这一波到了五十岁，也去是2030年2040年代开始，中国人的诺奖时代恐怕并不难预料。  实际上过去十五年，中国的科技产业发展也足见，10年代初大家都吐槽国产手机，15年左右国产电动车也是这处境，而23年中国已经在人工智能、新能源、电动汽车、机器人等各方面占据新峰。所以，科技角度，中国鼎盛时代恐怕还没到来而已。然而我至今还没去过美国，眼见为实，究竟未来鹿死谁手，我既不知，则不好说。

中国制度之未来。  
政治制度上，我看了两三年台湾政治，实在的，意识形态分辨很多了。  台湾的民主政治，好处是负责人都是公众人物，出问题了找得到具体的某个人，而中国大陆本质上是技术官僚专业队伍官官相护，好处是队伍稳定，但问题是官僚队伍没有退出清洗换血机制，泉无活水则腐也。 但是，人们对中国大陆威权体制挞伐，对台湾民主体制无脑称赞，对新加坡威权体制居然无脑称赞。 然而中国后新冠时代后，我也离开学校了，受到所谓中央的全国性影响其实小了————比如不需要读习概之类全国统一的钳制。 遍历各省后，才知道中国真正的政治是地方政治，尤其和新加坡对比，中国产业大爆发的根本，是因为各个地方政府的竞争，升职政绩战、人才争夺战、教育资源争夺战、产业园建设战等等，可以尝试用国际局势竞争思路来看中国各县市竞争格局，就能解开许多疑惑了。  然而各省的地理格局、历史脉络，全国内的局势都是完全不同的。  许多人谈的是分配问题，但你看生物和计算机的工作薪资，根本上是中国生物公司不足强，新加坡计算机岗位远远少于深圳，本质上，产业的区别，恐怕远远大于所谓政治体制的区别。饼不够大，没有这些公司、产业、国家整体实力作为大船，没有东西可以分配，恐怕谈什么制度都是空的。
但是中国未来的政治制度会优化么？先看过去三年，三年前习近平打破任期限制连任，破坏原则，某种程度上，可谓罪不容诛。不过现在看来，他并不能改变中国真正进入现代文明的趋势，整体上还是科技官僚治国，做出大突破的也不是国企的大国工匠，依然还是地方人才。 他最主要的影响，恐怕是提前开启中美对抗，清肃高层中的前朝旧队伍，党政重新合一，加强对民间的控制，然后在打破连任规矩上做了极坏的示范。 然而现在中美对抗后的平衡趋势、政策方向已经底定，中国实际上新的问题层出不穷： 就如人口结构，诸多问题目前显然中央是摆烂状态，等资本等民间活力试图解决之罢了。包括三年前担心台海战争，目前看来也是又相持下来了。  我看还是一样，得八零后九零后掌权时代来了，整体的人事格局变了才有新机会————中国倒是有这一点，精英足够多，会有进入政府中为人民做事的。  新一批的人，在国计民生上的底线、国际视野格局显然的是会高一些的。 实际上，政治上，中国大陆和台湾和新加坡的区别没有想象的那么大，真正大的区别恐怕是： 官员财产公开等透明制度， 责任人公开与落实溯源等制度， 弹劾检举舆论等纠错机制，民生发放机制等。  这些具体的制度设计与制度落实形成政治惯例，融入文化基因，这才是要点。
总而言之，政治激烈程度在这三年大为缓岬，未来制度整体上还是外儒内法，党政一体或者外政内党，还是地方政治，还是精英政治，这些恐怕再过三十年也没多大不同，外力现在不足够撼动这个体制。  现在没有足够的危机紧迫感让其改变了，东部核心区汉人主体格局极难改变，不会民族杂居则难以走向新加坡虚伪民主体制，党无对手则难以走向台湾多党制度，窗口已经过去了。
对于我个人来说，我也没兴趣去改变这个政治制度了，因为现在这个制度目前来看，虽然是文化领域的极大桎梏，但是对于科技领域并不怎么钳制反而整体是有利环境。我现在已经进入后者了，对前者的兴趣大为退却了————我更关心解决问题的后果。

5.三陷阱论/三大加速度论
第一加速度：被动收入超过日常消费开支（5万/人/年），即积蓄超过100万/人。——————一重陷阱，人为畜生，不劳则饿死。然而劳动并不能改变此处境的陷阱。
第二加速度：被动收入超过八小时工作制薪资（30万/人/年），即积蓄超过600万/人。——————二重陷阱，时间为赚钱机器，然而工作本身并不能改变此处境的陷阱。
第三重陷阱————人的欲望不能得到满足。  这只有历经万事，有些真想要实现的，尽力实现了，有些不确定想不想要的，探索后确认不想要了。   由此，人的欲望被填平，这就是人走向圆满也就是死亡最佳时刻，也就是所谓成佛的时刻。
然而其实关于第三重陷阱，我们知道有一个通用态度： （1）是非经历不知道，愿意去探索求证（2）愿意接受和尝试新事物，更新自我（3）知止于至善（4）虽不能至，心向往之，乃至心心念念，此所谓诚也（5）口说心证无凭，以行代言，以身证道（6）坚持不易，以时间证心也。    如此，不论你处在哪个欲望的处理阶段，都是在把内丹修炼得愈发圆满的过程之中。则无愧于道心佛心也。
你可以说和马斯洛需求理论有点像，但那个没有量化。
