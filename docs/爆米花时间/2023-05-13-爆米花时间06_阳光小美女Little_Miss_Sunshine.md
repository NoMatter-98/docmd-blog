#  阳光小美女Little Miss Sunshine

​

1、这部电影主旨很清晰，主线也非常清晰，就是一个反励志的故事。——一家人，老爷子想嫖女人想吸毒被赶出了养老院，父亲想贩卖成功学理论成为名人结果被商人一脚踢开，叔叔自诩美国第一红学大师结果奖项被授予了别人，哥哥想当飞行员但是色盲，妹妹想选美冠军但是并没有什么特别才能。

​

    2、不过这部电影实实在在是一部喜剧，那这部电影很体现喜剧的要领：一个普通人，有一个超越自己能力范围的目标，并始终在为之努力，并且始终是失败的。这也是曾博的“博学”、周星驰的喜剧等等有意思的地方，无论是人类还是哪个物种，其终极的命题是“命运”，而不是什么爱情啥的。真正的喜剧就在于此，比如经典的推车挂挡、![](/assets/images/tc/2023/05/13/42ff0446c2063.png)

老爷爷最后悔的是没有多艹几个漂亮小妹妹、偷老爷爷的尸体跑路，当然还有我最喜欢的一个镜头——“good, yeah~”![](/assets/images/tc/2023/05/13/b335bcb862a0a.png)

还有，小破车贡献了太多笑点。![](/assets/images/tc/2023/05/13/99fb17ed0f074.png)

以我自己的亲身实践来看，确实是要这种愣头青的精神，去搞那些看似遥不可及可是细想也好像确实有搞头的事儿，这样的生活乐子比较多。

​

    3、另外这导演还想说的是，如果不能拥有成功，那么做自己，有相爱的人，也是很nice的。这主要是Olive小妹妹最终明白，明星也吃冰淇淋、普通人也吃冰淇淋，成不成功其实和吃不吃冰淇淋没有绝对关系的，不必为了所谓的“成功”扭曲自身。

最后，我觉得一般人（比如我的叔叔辈或者兄长辈或者小屁孩们）看这电影应该觉得莫名其妙，比如老爷子也太不检点了，这个叔叔一遇到点事儿就想自杀，老外真是没有一点定力云云，一点正能量都没有，哈哈。I think so,而且这些人物都交待得好草率，爷爷忽然就死了，父亲要破产了怎么又不着急了，母亲整天打酱油，这个小哥哥又如何如何，总之会认为这电影每个人的戏份太少了，很多故事交待得不完整，我感觉看细节是可以发现变化的，如果我用一首诗，每个字有对应的双重意思比如本意+谐音，就能把这篇文章想表达的东西写出来， 那我也不会写这几百字嘞。短小精悍是水平，我觉得内容交待得蛮完整的了，当然可能并不是常规期待的那些内容，比如故事似乎戛然而止，但是这有点像留白，作者本身就不打算把那部分通过画出来的方式表达出来，甚至压根就没想表达“那部分”啦。

——商子羽
