#  宇宙探索编辑部

## 1、优点：
细节非常非常多（有一定欣赏水平的人看得还是会很爽的），各角色很有特点，风格是幽默而不是搞笑，运镜的设计有几处很有意思。



## 2、缺点：

-  **这是打着科幻片、喜剧片噱头的公路片甚至文艺片，个人觉得离大众的欣赏视角还是蛮远的。**这个片与其说是讲了个追寻外星人的喜剧科幻片，不如说是讲了个寻仙访道（蒲松龄那种）的黑色幽默的类西游片。讲的是伪科学的故事，so科幻味太淡、太不对味了，反而是很像求仙问佛一样——从开头到结尾，请尝试把“外星人”换成“仙”或者“佛”，是不是非常有感觉？那如果你要我说啥是科幻味儿，或许刘慈欣的《山》可以做对照阅读，你可以发现导演应该是有参考这个作品但是照虎画猫了。
- **伪纪录片的形式，更多的是小众或者说新奇，标榜的是“真实感”，但问题在不容易呈现美感。**这让我想起摄影界争论的“性能过剩论”"画质党数毛党"问题，在手机里早就没有争议了——不存在性能过剩，只是说对当下来说性能过剩，但是长期来看还是性能好的、画质好的能留存得更久，在电影里1941年的黑白电影“公民凯恩”再牛逼也没有1939年的彩色电影“乱世佳人”好看，而且所谓的牛逼在时代浪淘沙以后发现也就那样，人家乱世佳人也牛逼啊，经典拼的就是样样都要极致，单论立意、镜头语言等等可能都大差不差，那就是要在能拉满的地方都要拉满，尤其甚至首先是画面美感。所以我要是导演，我要追求真实感我可以一镜到底的拍摄手法解决呗，为了所谓真实感去追求做“伪纪录片”教父，我觉得得不偿失的，除非没钱拍，或者我就是为了当周杰伦宁愿扎根农学院做个农学院周杰伦。
- **除了唐长老和孙师兄两个角色以外，其他角色大多数虎头蛇尾。**你可以说这些都只是意象，比如说那个红帽子大叔（我现在管红帽子大叔都想叫马里奥）只是个意象，那ok，大姨、醉酒青年、凑数女孩都仅仅是意象喽？比较明显的是他们和主角的人物关系交代得比较松散、而结局交代上则相当随意，我个人怀疑是导演刻画人物之能力还差了点。

- **一个故事不一定要主动表达什么。但显然这个片是想说话的，可他说的话让我觉得差了点意思，有点像花了520捐了宇宙慈善箱一样。**主要是结尾的水平实在是有点捉襟见肘，西游的唐长老是为了普度众生的慈悲心或者事业心来取经的，那这个片的唐老师就很纠结，他开始是为了“人类文明的再进化”，后面又是探寻人生的意义，最后揭晓是为了搞清楚女儿自杀的原因，但是他最后怎么就和解了呢？最后给了个“貌似懂了”的感觉，实际上就是言之无物，当然有的观众应该会以为是余韵无穷。包括宇宙的尽头是DNA，包括雪花里的也是DNA，壁画上也是DNA，总之人类存在的意义就是DNA——“DNA”这个符号实在并不算少见，而“人生活着的意义就是活着”乃至萨特的存在主义，这些都是很常见的说法。那么他要表达的东西实在是鸡肋，是比一般的烂尾好一点，但是离一个不错的结尾差太多了，这不是说给女儿无声之诗就能糊弄过去的。导演搞这些花里胡哨的细节太多以后，正儿八经讲点东西讲不出来就有点说不过去了。

## 3、再聊聊这个科幻的问题。
尤其是麻雀包围孙师兄升仙这一段，实在是乡野狐仙怪谈的味儿太冲了，**整个电影从视觉上就没有啥科幻带来的“未来感”“科技感”的元素**，你就算是给一个进太空舱发现他是三维全息投影的操作屏、耳机或者鼠标不是放在桌子上而是磁悬浮支架上等等也好啊。人家京剧讲究“亮相”，一打眼看出这角儿怎样，我这左瞧右瞧没看出他的科幻相。再说他有一段想问外星人“存在的意义”，回复是“万一外星人也是来问这个的呢？”这一段真就《山》了，**很多软科幻有一个点在于“思维实验”的观感，去从“文明”这个角度思考终极问题**，像刘慈欣的山也是一个痴人遇到了一个外星文明的对话，但出彩在外星文明而不是这个人，也就是出彩在文明这个视角，把文明和个人有点挂钩起来，我举个名词叫“文明之性格”用这个方式来帮助读者，通过一个人对于爬山的追寻来同理心去理解那个外星文明对于宇宙边际的追寻，从这来看，非要说的话，以文明来思考或者展现终极问题是一个我个人现阶段认为比较典的软科幻特征。然而这个片可惜在并没有爬到稍微大一点的视角，还是致力于解剖一个痴人，实在是难以说得上什么科幻。




总而言之，这片子，离“经典”这个水平太远了，从画面、人物角色的刻画、故事的表达上都有太多可以挑剔的地方了。但是这片子的细节密度相当之大，在它伪装成“随意”这个基调下更加容易让人有跳蚤市场捡到宝贝的兴奋感，而且他这个故事很典型得独特，因而就有了睡桥洞的流浪汉吟唱诗歌的气质，我倒是挺推荐有一定欣赏能力的人去看一看的，甚至我看过的国产片里面确实可以列进必看系列。不过对于大众我是不建议去遭罪的，且对于要对导演顶礼膜拜的那种博客播客的吹捧嘴脸，我实在是反胃。老实说导演也就郭帆一小弟水平，郭帆在好莱坞的话也未必有啥统治力，实在是想对没见识还没魄力的播客暗挑大中指。




——商子羽
