# 爆米花番外之演唱会篇

## 周杰伦2004无与伦比演唱会

​    1、我特别感动的是：**梯田+爸我回来了。还有外婆**。这个我不是第一次看，但是确实还是很受感动，非常喜欢。

​	2、老实说忘词、乱节奏等等不少啊，还有我觉得《在我地盘这儿》的把弹头比作狗儿实在是难以称作好的处理方式，当然没必要像举报HOUSE一样，我就是吐槽一下，因为居然没有人吐槽这一点。

​	3、那么为什么这么多人唯爱这一场？看评论觉得可能是很多人在这个时候入的杰伦的坑，所谓“哇我的青春啊”云云，妈耶真的是在谁那里都看得到“哇我的青春啊”，李宇春也是你青春、许嵩也是你青春，鸡你太美也是你青春，对这种论调总是刷得到时候就很无语啊，好像这观众已经要入土了一样，我以为有的无非就是卖弄一下“资历”，无语。

​	4、此外的话，这场演唱会上南拳妈妈的歌从词、旋律、节奏都是校园青春那个调调，不过唱得还行但不算很6啊。

​	5、总得来说没觉得特别超神、完美等等，和王力宏的2008Music man我觉得演唱上没有那么好诶，至于陶喆的Soul Power，这就还是有差距的叭。当然相比而言，不得不说的是他的**画面美感，包括服装、字体、舞蹈非常nice**，以及风格特别松弛就很好。
