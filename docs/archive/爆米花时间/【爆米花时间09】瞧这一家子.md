# 瞧这一家人

## 总评

咱得考虑到这是1979年上映的片子。

- 虽然在配音、配乐、表演、剪辑上，很多都跟不上时代了。但是它起码做到了两点：准确和特色。举个例子，比如配音，虽然音色有些地方刺耳、有的地方音画不同步，不符合人物动作特点，但是还是符合人物性格和当时场景要表达的情绪的。
- 然后在<b>剧本</b>这种几十年来发展早已经比较成熟的元素方面，有不少地方还是很厉害的呢！尤其是“和解”的设计：父亲的顽固与女儿、徒弟如何用“黑脸”一笑了之；互相投诉的消费者与服务商身份互换，而老父亲是主动上门致歉，这种“互相对立的身份”相互转化，看不同的人在同一个身份时不同的表现，可以得到很多启示的。
- 当然有些地方设计得像写作文一样过于<b>工整</b>了。比如开头合影，结尾也合影。开头是花开了， 结尾送花。开头是“什么事情让你一搅合，就全乱了套了”，结尾又要重复这句。怎么说呢，我在想是否有更有趣的表达，尤其是结尾的合影那里实在太快了，忽然就领证（甚至只是口头提了句“下午领了证”）了然后合影，有点刻意了，要是他变成“要是以后拍照能够在家里随手拍就好了”那我觉得就很nice了。——没错，我可以这样处理，开头是要去搭乘飞机，然后结尾说以后要是能从家里起飞就好了，嘿嘿，一部作品要留那么点（预言）内容是给未来人看的，这应当成为我的创作理念。
