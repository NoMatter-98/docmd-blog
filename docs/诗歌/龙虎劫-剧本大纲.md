# 龙虎劫（剧本大纲）

林佳龙是谁？

思路：
- 镜头感
- 音效bgm
- 文字的节奏感
- 文字的谐音梗、典故意象
- 两两对比（两次酒局/两次茶会，两次参佛，两次面对死亡，两次面对医生（帮领导取药和自己老婆要死了））实现一个连接感
- 人物关系图

加入一点猫猫动物以及植物等代表意象

开头的设计：龙吟虎摇头啸-跳出来抓人镜头感，人字（老字号——说明这个主人公喜欢玩谐音梗的幽默感）拖的导演名录设计（当然可以看看角色参演人员名单设计，比如毕业典礼的合照云云）

怒：父母去世前留下的只有族谱——夜深，老婆起身发现龙在翻开来看看故事，讲老爷爷回老家被看不起，写的小诗。
实习被骗走。
考试烟草局第一名被刷走。

过年老家皇帝的新衣的小男孩——为什么不去卖菠萝？

苦：
饭局老板——让龙端茶倒水，（龙井茶），配喝酒——白的，不等你喝完就给你添、敬酒时候小弟们互相拜在地下（这个要安排外卖小哥们的酒局做对比），大老板直接叩一下桌面。吹嘘自己操过几个处女。
	饭局老板介绍——做新媒体的，做互联网的。
有艺术家朋友——半夜来见客，评价相貌（有点相术），骂猫咪总是抓他，上厕所来偷袭，稍微给不好吃的就耍脾气——要暗示老板后来的驭人之术。
艺术家朋友家里有个纸箱子，猫呆在里面，反而猫窝不待——焉知哪个是在他们眼里真正好的家呢？唐僧待在皇宫里焉知实际上比待在盘丝洞里好呢？
有文学家朋友——铁观音茶。（参照去灵隐寺那次，要讲到观音、地藏王）
有回母校做讲座的同学等等。——我也不知道能告诉你们什么经验，毕竟学弟在研究跑车。

新媒体朋友的故事：编导+方猫boom：佑禾面包，老婆好久没吃过了——这个月一定要赚到多少多少就去吃——编导的故事。
给领导的小孩做家教——领导有一次生病，直接单位预约了最好的医生，单位报销。
老婆没时间去老家打九价。
