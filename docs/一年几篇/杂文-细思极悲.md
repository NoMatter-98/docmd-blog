# 杂文-细思极悲

好久没写文章了，一转眼到了11月，天气凉了，然而今天忘了添衣，下午还是一件长衣长裤就出门了。晚上十点我从东六回望月时，冷得只开了十码的龟速，还是冷得很。

昨天和师姐一块画图画一天，晚上走时她说像高中生放学一样，我没说啥，我没有这种记忆，因为高中放学都是自己回去的，绝大多数时候也是自己吃饭。

1. 老天爷赏饭吃，我其实没得选。

前几天回了老家，但是士气反而更加低沉了。今天上午就呆呆地躺在床上不知道该做什么，好像一个八十岁，妻子儿女都天人相隔，而什么志向和努力已经意义不大，还能做的事情没有什么选择余地，前路的命运如同天色一样，不用抬头看就知道是不是下午了，还有多久就到晚上了。我也一样，做卷子？努力不努力都是中科院，也没法知道是不是塞翁失马，但是要点在于好像拿到的都是一眼看上去就知道能拿到的，就是最好的选择，说白了就是那句“老天爷赏饭吃”。

2. 一群人做事无趣难免自己做，自己折腾不动了又无趣

那么我前段时间做的那些，又是申请硕士要上网课拿证书，又是要考虑考托福拿英语成绩，又是CS的AI项目等等，但是最近几天也完全没有想折腾了。

![image-20231108000859561](./assets/image-20231108000859561.png)

前两天回一趟家，发现父母压根不关心我的未来情况了，比如我父亲不晓得读博士是要五年的，他以为是两年博士。完全是一幅“我的任务已经完成了”的躺平心态。我倒不是觉得父母见识少什么，悲凉的是，我关心感兴趣的东西没人在乎了，在我读大学前父母非常关心读大学而如今我下一步的前程却完全是不想了解了，即使我自己关心想聊这个话题。不单是这种人生规划的事情，有个小事也让我难受，起码两年前我父亲说想换个相机，因为他的一个工作是拍照洗照片，而使用的相机是十年前都只需要两三千的数码相机，效果可想而知。而两年后，我买了第二台相机了，父亲还是没有买相机，我带回相机，想分享我摄影的作品，却并没有引起兴趣。这种感觉就好比去街机房想跟老板聊自己喜欢的游戏，但是老板压根不关心只是挥挥手说别烦我，记得三国志赤壁之战游戏中间吃包子那里不准狂转摇杆。



折腾得多就会明白，大多数情况都是自己去做，不大能指望有人一块搞或者有人教，因为大多数人都不会觉得有啥意思，关心了也没钱这类收益。折腾要紧的就是自己觉得有意思。但是自己做没人带就是很麻烦很麻烦，不太可能有稳定预期说一时半会后就能有什么结果。一旦自己给与自己的反馈——也就是自己觉得有意思的热情，消退后，就不会想去做了，因为吃力不讨好。



于是在这个清凉的马路上，我想起真正属于我的高中记忆——读日记。我记得在离高考也就几个月时，我已经准备好以不到六百分的高考成绩就考个华北电力大学罢了，有天我忽然想到自己已经写了这么多年的日记，也不乏那种“写给未来的信”等等，何不读一读呢？于是有天还是自己一个人吃饭，一边就拿出那几本日记慢慢看，看着感到非常有趣，因为那些曾经觉着有趣的问题我那时还是觉着有趣，或许有了新观点、发现错别字等等就很高兴，拿出红笔在旁边批注一下。我一直不理解自己为什么会做这么无聊的事情，今晚我明白了，因为确确实实这些问题，实在很难有周围人觉着有趣的，别说有趣，就是能理解我为什么觉着有趣的，都是几乎没有的啦。而读日记就有了一种错觉，“噢也有人觉得是这样啊”，激活了自己对那些问题的乐趣。



其实我上大学后写日记少了很多，即使有也基本是记账这种，完全不是高中初中那样记录自己所思所想了，所以四年过去了我完全没有整理过日记没有看过日记。有段时间我还感到悲凉——多么孤独的人才会读日记读得好像遇到好朋友一样啊！但是确确实实我感到，大多数情况下做事情都是独自打拼，没人注意自己的生活进程，而没有家乡、朋友、家人、同事的注意和或多或少的帮助，做事情实实在在地是要资源没资源，要乐趣没乐趣，遇到问题也只能自己试解法，这过程常常是令人沮丧的。只能自己有Just For Fun的热情才行，这是没办法的办法了，当时对读日记这事情深深感到悲凉，因为知道这种孤寂恐怕是一辈子的事情，现在接受这现实，也就珍惜每个还能感到乐趣的自己，珍惜每个还能理解这种乐趣的朋友了。

3. 很多困境就摆在眼前，迟早绕不过去

大一大二时绕不过去的困境（那时候还没有像疫情后期那样教培、房地产、互联网、金融全部被打趴）就是原来出身已经决定了我连不愁钱都竟然做不到，十二年读书下来竟然根本没有治国平天下实现抱负的资格，比封建时代科举考上好歹有个县令都差了太远太远。确定了计算机方向博士科研或工业界创业，这种技术出发积累团队的路线后，才算找到跨过困境的办法。但是还是有很多摆在眼前的事情——父母待在遥远小县城是很麻烦的，外地人来江浙沪和本地人结合的婚姻是很麻烦的。但是其实配偶最难的还不是家庭背景的匹配，而是那种安全感，交流和共事都不需要老是小心什么，老是伪饰自己，因为能够被理解的预期啦。而家庭，注定是决定性的要点——一个人能做成还是做不成，正常人自己个人的努力能起的作用实在让人绝望得小。



所以很多事情想起来是真得悲：

- 一个人，看似有很多选择，其实之前的条件和当时的认知范围决定了适合的路就那么几条，最优解是找得到的，最多两三个可选项，完全不是自己想干啥就能干啥，只能吃“老天爷赏的饭”。

- 一个人最重要的是与自己相关的这一群人怎样，自己能凭自己再提高很多么？太难太难。
- 但是与自己相关的这群人很难有志同道合的，难免还是要自己干。
- 折腾不动，就难免无聊了。

没错，一个人最后就是这么的无聊，无趣，无解起来了。



但是这就是为什么我也感到师姐说的那种高中生放学回家的感觉。有时候就是这样，本来没啥意义没啥意思的事情，虽然俩人做还是没啥意义也没啥强烈的情绪，但就能“有点意思”了。而有意思不用多，有一点就很够了。
