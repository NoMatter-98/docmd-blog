# 电影观赏笔记

## 劳工之爱情

1. 简评：现存最早的完整中国电影，1922，默片，短片（22分钟），故事幽默挺有趣。
2. 有趣之细节：
   - 尤其是为了追女的，把下楼的楼梯改装那一段，按照传统封建礼教那显然是要批判的——为了儿女情长，做陷害他人之事，况且被陷害者还有老人。这种不拘一格的幽默有点猫和老鼠那种意思了。
   - 刚开头切西瓜那会儿怼脸拍，真的是类似京剧演员讲究出场亮相就要让观众眼前一亮，此面相、动作一出就觉得是个喜剧演员嘞。

## 阳光灿烂的日子

1、简评：蛮有趣的电影。

2、有趣之细节

- 冯小刚演的并不算好
- 青年马小军这十六岁左右的脸加上一身的肌肉，太TM有型了。
- 有播客说《三体》电视剧拍出了文革的感觉，我觉得差太远了，当时想到的是《末代皇帝》结尾红小将女兵整整齐齐得批斗挥旗那一段。看看这部电影才更加对，尤其是妈妈生孩子那一段，马小军一点也不担心妈妈，而是觉着“这种战备观念，要是帝国主义发动突然袭击，还不全他妈完蛋”
- 这部片子确实是很多细节值得称赞，尤其是情绪的表达并不单薄，比如表达悲愤一定要掉进坑里以后肉体上的痛引发身体上的痛，才会哭喊出来、飞向克里姆里宫之后才会引到烟囱去等等。
- 尤其是记忆混乱这个点，表达得很符合有一定年纪后的人自行修改记忆的特点。
- 但是整个故事就是爱情故事，给我一个参考咋写最近构思的故事。
- BTW我不喜欢宁静和陶虹，前者太胖后者太媚，并不觉得很好看。



## 阿Q正传

1、观念之转变——我不是想做品头论足之评论家，那么必须得动手写写，只有这样才能欣赏到更多光看不做者欣赏不到之处。因而每周还是看，但是未必长篇大论写评述，而是着重挑其中给我创作有灵感之部分做做笔记。

2、有趣之细节

- 阿Q的精神胜利法只是一个特征，他必须要搭配上“你也配姓赵、你也敢姓赵”的赵太爷、笑着说“这次不是儿子打老子了啊，说人打畜生”的伙计、假洋鬼子动口斯文动手粗暴，才能有趣。——也就是光有“人设”，不行，必须得安排此人与他人发生之事件从而体现此人之人设，此与网文拉开差距之处也。

- 阿Q直接交大——现在男的也这样，把表白当做冲锋的号角而不是胜利的凯歌，哎，我能理解他。不过女的被吓跑后他并没那么伤心，而是懊恼，然后是哼一声“假正经”，这就对了。如果我要些一个纯憨憨，那他应该也不是伤心，而是懊恼，然后就是疑惑不解，不知道自己哪里做错了，此所谓相同之举动不同之反应体现人物之性格。

- 从阿贵姓什么？通过“你也配姓赵”到精神胜利法，通过尼姑事件到女人主题。衔接非常流畅。
- 从阿贵叫困觉后被打那一次那一下，可见这电影排的还是很真很狠。
- “这时你们都不怕阿贵啦？”  乐。
- 小鸭子浮起来，从桥底出来，这种场景我也能写。
- “老子要革命”乐。 我也可以写个“老子也要AI、元宇宙、去中心！”之类的，然后搞个表面功夫，实际上是捞钱捞好处的本质，巧立名目赚钱呗——手机颜色叫什么水晶蓝、樱桃红啥的，“借鉴一下键轴”。然后VR的摄像头。六个手指头，第三个眼睛放在屁股上等等。

- 画圆圈这个很荒诞感，但是没有朋友、没有亲人，包括祥林嫂什么的也类似于此，总让我觉得不真实，这是以前人的情况么？这不应该是后现代人的现状吗？
- “我没有家”“送你回家啦”

- “唱个戏叭”“二十年以后又是一条好汉！”“好！~”“大家都白跟了一趟”

- ”而且子孙繁多，至今不绝。“  好啊，确实好！这确实用文字能撑起一部电影嘞！
